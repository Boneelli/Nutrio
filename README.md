# Nutrio - Progetto di Interazione Uomo-Macchina <img src="app/src/main/res/drawable/nutrio_nobackground_verde.png" alt="NUTRIO" width="20">
Nutrio è un ecosistema digitale nato per supportare studenti universitari fuorisede e giovani lavoratori nella gestione di una corretta alimentazione, aiutandoli a conciliare ritmi frenetici e salute.

Questo progetto è stato realizzato per il corso di Interazione Uomo Macchina (IUM), A.A. 2025/2026, presso il Dipartimento di Informatica dell'Università degli Studi di Salerno.

---

## 📌 Finalità del Progetto

Il repository contiene l'implementazione del sistema progettato durante il corso. È fondamentale notare che:

* **Focus sull'Interfaccia:** L'applicazione ha lo scopo di mostrare l'interfaccia utente e i flussi di interazione per permetterne la valutazione.
* **Dati Simulati:** In linea con le specifiche d'esame, il sistema non utilizza database reali; tutti gli account, le ricette e le informazioni sono inseriti direttamente nel codice (*hardcoded*) per simulare il comportamento del software durante i test di usabilità.
* **Prototipazione Funzionante:** Il codice permette di navigare realmente tra i flussi principali, passando dalla fase di sketch e prototipo Figma alla verifica su un sistema funzionante.

---

## 🚀 Task Implementati

L'app permette di testare 4 task fondamentali definiti per risolvere le criticità del target (poco tempo, stress decisionale, sprechi):

* **T1 - Scoprire una nuova ricetta:** Ricerca avanzata con filtri per tempo, costo e intolleranze.
* **T2 - Creazione e pubblicazione:** Form strutturato per l'inserimento di nuovi contenuti.
* **T6 - Creazione di community:** Strumenti per organizzare nuovi gruppi tematici.
* **T7 - Cucina Assistita:** Interfaccia dedicata alla guida passo-passo con simulazione di assistenza vocale proattiva.

---

## 🛠 Note Tecniche

* **Tecnologia:** Sviluppato tramite Android SDK in ambiente Android Studio.
* **Architettura:** La logica e i dati sono gestiti localmente nel package `com.example.nutrio`.
* **Design:** L'interfaccia traduce i paper sketch iniziali applicando design pattern specifici per l'HCI.
